# usque OPNsense package repository

Signed FreeBSD pkg repository for the experimental os-usque plugin and the usque-nativetun runtime.

Current catalog:

- OPNsense 26.7
- FreeBSD:15:amd64
- os-usque and usque-nativetun only

See the project README for installation and verification instructions.

This is an independent research project. It is not affiliated with, endorsed by, or reviewed by OPNsense or Cloudflare. Third-party repositories are unsupported by OPNsense. Back up the configuration and take a snapshot before installation.
